料金と条件

すべて無料です。登録・ログインは不要で、入力した内容がサーバーへ送られることはありません。プロフィールはこの端末に保存され、いつでも再入力・修正できます。

診断について

骨格とパーソナルカラーは、短い質問への自己チェックで傾向を出す簡易診断です。結果は似合う傾向の目安であり、断定するものではありません。顔印象は自己申告です（写真の判定はしません）。

占いについて

今日の運勢は、日付から機械的に決まる娯楽要素です。同じ日なら、誰が見ても同じテーマになります。そのうえで、診断タイプによって選ばれるバフが変わります。
